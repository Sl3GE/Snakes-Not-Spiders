# Snakes Not Spiders

A resource pack for people who would rather not see spiders. Spiders and cave spiders are replaced with blocky snakes. Nothing else in the game is changed.

**Minecraft:** Java Edition 26.3

## What changes

- Spiders become dark snakes with a yellow stripe
- Cave spiders become smaller blue-grey snakes
- Their bodies sit in an S-curve and slither from side to side while they move
- Names change to match: Snake, Cave Snake, Snake Spawn Egg, Cave Snake Spawn Egg, Snake Eye, and Fermented Snake Eye
- Spawn eggs and both eye items use new icons

Cobwebs, sounds, and other mobs stay the same. Spiders still move, attack, and take up the same space as before. Only how they look and what they are called is different.

## What you need

Install **one** of these. Do not install both.

**Entity Model Features** (recommended)

- [Entity Model Features](https://modrinth.com/mod/entity-model-features) for 26.3
- [Entity Texture Features](https://modrinth.com/mod/entitytexturefeatures) for the same version (required)
- [Fabric API](https://modrinth.com/mod/fabric-api), if you are using Fabric

Works on Fabric, Quilt, Forge, and NeoForge. Pick the files that match your loader and 26.3.

**Or OptiFine**

- [OptiFine](https://optifine.net/downloads) for your Minecraft version
- Turn on **Video Settings → Quality → Custom Entity Models**

Entity Model Features does not work with OptiFine or OptiFabric.

Without one of these, the pack can still load, but spiders keep their normal shape and only the textures and names change.

## How to install

1. Install the mods above and launch that version of Minecraft once.
2. Download this pack.
3. Put the zip in your resource packs folder. Do not unzip it.
   - Windows: `%appdata%\.minecraft\resourcepacks`
   - macOS: `~/Library/Application Support/minecraft/resourcepacks`
   - Linux: `~/.minecraft/resourcepacks`
4. In game, open **Options → Resource Packs** and move **Snakes Not Spiders** to the selected side.
5. Press **F3+T** if you already have a world open.

You will know it worked when a spider looks like a winding snake instead of a mob with eight legs.
